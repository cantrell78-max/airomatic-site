How to play

  1. Three chassis, each a different paint.
  2. Parts are color + type (e.g. TEAL CAB).
  3. Every part has a home — aim for the matching color bay.
  4. Move + rotate, then snap onto the ghost.
  5. Guides: L1 all base parts · L2 canopy only · L3 bumper only · L4+ none.
  6. Finished truck drives off; a new color rolls in.
