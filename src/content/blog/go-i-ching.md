**現在就下：** [airomatic.ai/go-i-ching](/go-i-ching/)

子未落，太極未分。落下第一子，陰陽始生——這不是文案，是這款遊戲開門時，旁邊那位老人真正會說的話。

我們把 Grok Build 指向一個安靜、卻不容易做薄的想法：**圍棋（围棋 / 囲碁 / Go）與《易經》本是同一條道。** 黑白是陰陽，交叉點是變，空點不是「還沒填上的格子」，而是尚未生成的萬物。棋盤要像一幅還活著的曼荼羅；旁邊要有一位先生，不只是裝飾，而會讀眼前這盤棋。

於是有了 **《圍棋易經》**。

## 你在下什麼

瀏覽器裡一盤完整的圍棋，不必安裝、不必登入、可以離線：

- **規則：** 交叉點落子、氣盡提取、禁止自殺、打劫不可立刻回提
- **點目：** 中國子空計算法（活子 + 所圍之空），白貼七目半
- **棋盤：** 九路（預設，適合入門）、十三路、十九路
- **對局：** 雙人對坐，或與「易翁」對弈（九路 / 十三路用蒙特卡洛，十九路用較輕的形勢判斷）
- **棋盤上的事：** 停著、投子、悔棋、點死子、存譜、讀譜、導出 SGF

畫面走水墨與木紋：宣紙底、松煙線、帶一點高光的黑白子。沒有音效——這次刻意先不做聲，把氣力留給棋與卦。

## 為什麼要把易經放上棋盤

圍棋本就在講先後、厚薄、取捨、空與勢。易經本就在講時、位、陰與陽、既濟與未濟。硬把兩件事黏在一起，會變成課本彈窗；真要融合，先生必須**從當下盤面長出話來**。

所以易翁不是旁白機器人。他看的是：

- 誰更厚、誰更薄，哪一隅先成勢
- 剛剛是提子、是打入，還是天元
- 布局、中盤、官子各像什麼季節
- 西北乾天、東北艮山、西南坤地、東南巽風，中央太極

你隨時可以按 **「問先生」**。程式會讀子數、厚薄、角落與中央、近幾手的提子，選出一卦（以及一卦次應），再把卦辭還給**眼前這盤活棋**，而不是還給書冊。終局時，他會把整盤讀成一組卦，然後說：勝負是一季之果；你在盤上學到的變，才是明年的種子。

六十四卦都在 **卦象典藏** 裡，可檢索、可點開。開 **悟道模式**，他會說得更勤，也更願意講氣、眼、空、劫——劫，在他嘴裡，是易的縮影：一點不得即復，除非四周已變。

## 中文，或英文

棋是中國的，這本書也是。遊戲裡有一枚始終在場的切換：**中文 / EN**。介面、啟蒙、卦辭、易翁開口，全部跟著走；選過一次，瀏覽器會記住。中文用繁體，為的是跟《周易》的書寫傳統、也跟棋盤上的「圍棋」「停著」「點目」放在同一種語氣裡。

你現在讀的這篇日誌，預設也是中文。右上那枚切換，是同一件事的另一面。

## 啟蒙怎麼走

左邊控制欄（窄螢幕先按 **菜單**）裡有 **啟蒙**。易翁用七步帶你走過規則，同時把規則說成道理：

1. 坐下。圍棋與周易，一道之兩面。
2. 把第一子放在**交叉點**上——不是方格裡。
3. 氣：中央四、邊上三、角上二。氣盡則提。
4. 練習提一顆只剩一口氣的白子（紅圈會呼吸）。
5. 劫：戰也要呼吸，不可立刻回提。
6. 子空與貼目。你守住的空，與子同等真實。
7. 停著兩次即終局。隨時可問先生。

課成之後，自動開一局九路，你執黑。

## 技術上我們選了什麼

| 一塊 | 選擇 |
|------|------|
| 運行 | 瀏覽器，單資料夾即可離線 |
| 畫面 | Canvas 木紋棋盤 |
| 邏輯 | 原生 JavaScript，無框架 |
| 對局引擎 | 提子、劫、中國子空、SGF |
| 易翁 | 盤面分析 → 六十四卦對位 → 雙語解讀 |
| 掛載 | `public/go-i-ching/`，與站上其他小遊戲同一套 Cloudflare 靜態資源 |

沒有後端，沒有帳號。棋譜進 `localStorage`；要帶走，就導出 SGF。
