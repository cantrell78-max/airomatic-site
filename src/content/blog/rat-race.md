**现在就跑：** [airomatic.ai/rat-race](/rat-race/)

X 上的注意力是有限的。大家挤在同一个按钮前发帖、抢热度、再逃开审核——这不是隐喻说明书，是这盘游戏的规则本身。

我们把 Grok Build 指向一个并不小的玩笑：**社媒的老鼠赛，就做成一只真的老鼠赛。** 俯视赛博巷道，湿沥青，霓虹汉字，几只戴项圈的老鼠抢一台写成 X 的饲料机。饲料会吃完。吃完的人里，腮帮子最鼓的赢。待太久，穿警服的猫会来。

于是有了 **《老鼠赛跑》**。

## 你在跑什么

浏览器里一盘俯视 2.5D 小游戏，不必安装、不必登入：

- **目标：** 冲到巷子北面的 **X-FEED**，按住空格（或 E）吃金色饲料
- **倒计时：** 机子里的饲料是有限的。堆在变矮。吃光，饲料最多的老鼠获胜
- **变胖：** 越吃越圆、越慢。瘦老鼠能钻窄巷、甩掉猫；撑了就钻不过去
- **猫：** 喵兹警长沿巷巡逻。你在 X 上制造噪音，它会来查。被按住会掉出一地饲料，别人能捡
- **躲：** 垃圾箱、电视机、冰箱、纸箱、油桶。要躲在障碍物**背对猫**的那一侧
- **对手：** 韦克斯（谨慎）、面条（贪）、转进（捡漏）——三只 AI 老鼠跟你抢同一堆注意力

画面是 16-bit 像素、雨、霓虹。墙上的字是真的中文：鼠、内卷、关注、投喂、赛跑、老鼠。躲身的杂物贴着失败创业的名字——FLEETFIX 垃圾箱、FRYSK 电视墙、DRAFX 冰箱、PIVOT 纸箱、COLDSTART 油桶。

## 为什么是 X，为什么是老鼠

发帖像冲向同一台机器：有限的颗粒，看得见在变少，站太久会被「秩序」撵走，吃太多会跑不动。旁边永远有别的老鼠，比你更贪、更怂、或更会捡你掉在地上的东西。

所以饲料不是装饰。它是钟。猫不是随机怪物。它是你待在按钮上太久的代价。胖不是惩罚皮肤，是速度与缝隙的物理。

## 中文，或英文

游戏默认是**简体中文**。标题、按钮、状态、结算、提示，全部跟着走。标题画面和局内都有一枚切换：**ENGLISH / 中文**。选过一次，浏览器会记住。

像素字体画不出汉字，所以中文界面换成站酷快乐体与思源黑体——否则「投币开始」会变成方框。英文则回到那种街机点阵。

你现在读的这篇日志，预设也是中文。右上那枚切换，是同一件事的另一面。

## 怎么跑

- **WASD** 或方向键移动（相对镜头）
- **Shift** 冲刺
- 在 X 旁按住 **空格** / **E** 吃
- **P** 暂停
- 手机：左边摇杆，右边冲刺与投喂

瘦的时候把猫甩掉，钻回杂物后面，等它走远再回去吃。贪到走不动，就是猫的晚餐预备。饲料见底前，掉在地上的那些仍算数——别让它们卡在墙缝里结束不了；我们后来修过这一刀。

## 技术上我们选了什么

| 一块 | 选择 |
|------|------|
| 运行 | 浏览器，Three.js 正交俯视 |
| 画面 | 像素广告牌精灵 + 砖墙、湿沥青 |
| 逻辑 | 原生 ES 模块，无框架、无后端 |
| 对手 | A*、躲藏、捡漏、卡住会自己挣开 |
| 语言 | 简体中文默认，英文可切，记在 localStorage |
| 挂载 | `public/rat-race/`，与站上其他小游戏同一套 Cloudflare 静态资源 |

没有账号。声音是程序合成的雨与低音。点一下屏幕，音才开始。
